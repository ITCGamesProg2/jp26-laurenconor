# As a player(thief), I want to be able to collect points (paintings/ jewelry) so I can move to the next level in the game  
### acceptance criteria

- [ ] Use WASD keys to move towards jewelry 
- [ ] Keycard must be collected 
- [ ] Jewelry cases must be unlocked 
- [ ] Jewelry and painting spawn in set points on map 
- [ ] Items have different values  
- [ ] Points go up with collected items 
- [ ] Items disappear once collected

# As a player(thief) I want a random number of enemy’s (guards) with different skill levels to attack me so I can show off my skills 
### acceptance criteria
- [ ] Once player is in sight the guards move towards player 
- [ ] Guards will follow the player once spotted 
- [ ] Player will get caught when they get hit with the guards tazer 
- [ ] Each guard will move at a different speed  
- [ ] Player has to sneak up on /knock out a guard to get key card (opens jewelry cases and the exit door)

# As a player(thief) I need to get as much items as I can before the timer runs out so I can move on to the next level 
### acceptance criteria
- [ ] Hide from enemy's (guards) 
- [ ] Steal a key card from guard 
- [ ] Unlock jewelry case & take jewelry
- [ ] Steal paintings 
- [ ] Use keycard to exit level

# As an enemy (Guard) I want to be able to find/ capture any player (thief) so I can send them to jail 
### acceptance criteria
- [ ] Vision cone (flashlight) to help spot player 
- [ ] Enemy moves around the map in randomized patterns 
- [ ] Follow and try to taze player if they are in line of view (inside the cone) 
- [ ] Move at different speed
